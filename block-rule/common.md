| 要素 | オーサリングルール | 備考 |
| --- | --- | --- |
| 見出し | Wordの標準機能でテキストのスタイルを「見出し」に変更するとHTML上でもHeadingに変換されます。<br>以下は変換仕様です。<br>◼️見出し変換<br>見出し１ → Hading1<br>見出し２ → Hading2<br>見出し３ → Hading3<br>見出し４ → Hading4<br>見出し５ → Hading5<br>見出し６ → テーブルの見出し<br>◼️装飾<br>太字部分は青い強調色（#166DFF）になります。 |  |
| ボタン | テキストにリンクを挿入するとボタンに変換されます。<br>ボタンカラーやスタイル⁨⁩は以下のルールで変更可能です。<br>◼️カラー変更<br>・青（デフォルト） → 通常テキストにリンク挿入<br>・白 → 通常テキストにリンク挿入＋斜体<br>・枠線ボタン→通常テキストにリンク挿入＋太字＋斜体<br>・オレンジ → 通常テキストにリンク挿入＋取り消し線＋斜体<br>・テキストリンク→通常テキストにリンク挿入＋太字	<br>◼️アンカーリンク設定<br>・アンカーリンク → 通常テキストにページ内リンク挿入<br>|  |
| リスト | 箇条書き、連番それぞれWordの標準機能<br>２段目以降はリストアイコンが自動で変わります |  |
| キャプション（注釈） | Wordの標準機能でテキストに対して、リスト（箇条書き／数字付き）かつcode（フォントがCourier New）を適用するとキャプションに変換されます。 |  |
