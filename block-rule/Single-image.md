## ▼imageブロックに適用可能なバリエーション一覧

| **バリエーション名** | 適用内容 | 備考 |
| --- | --- | --- |
| col1<br>col2<br>col3<br>col4<br>col5<br>col6 | 1カラム〜6カラムまでの間でカラム数を指定します。 | カラム数分のセルを追加します。 |
| width90per<br>width80per<br>width70per<br>width60per<br>width50per | width90per：コンテンツ幅に対して90%<br>width80per：コンテンツ幅に対して80%<br>width70per：コンテンツ幅に対して70%<br>width60per：コンテンツ幅に対して60%<br>width50per：コンテンツ幅に対して50% |  |
| link-all | 画像全体にリンクを設定します。 | 設定するリンクはブロック列の2列目に記載してください。 |
| image-align-left<br>image-align-center<br>image-align-right | 画像の寄せを指定します。<br>・image-align-left→左寄せ<br>・image-align-center→中央寄せ<br>・image-align-right→右寄せ | セクションメタデータとブロックバリエーションで画像寄せの指定が競合した場合は、ブロックバリエーションの指定を優先します。 |
