## ▼各セル内のオーサリングルール

### **１列目**

| **入れられる要素** | **オーサリングルール** | **備考** |
| --- | --- | --- |
| 画像orアイコン画像 | バリエーションに何も付与されなければ、カード幅いっぱいに表示
icon表示にしたい場合は「icon-S,icon-M,icon-L」のどれかを付与する | 表示/非表示化 |

### **２列目**

| **入れられる要素** | **オーサリングルール** | **備考** |
| --- | --- | --- |
| 見出し | Wordのフォントスタイルを「見出し3」に設定 | 表示/非表示化 |
| ノーマルテキスト | Wordのフォントスタイルを「ノーマル」に設定<br>文中リンクの挿入も可能 | 表示/非表示化 |
| 箇条書きテキスト | Word標準の箇条書き機能を使用 | 表示/非表示化 |
| 連番テキスト | Word標準の連番箇条書き機能を使用 | 表示/非表示化 |
| キャプション（注釈） | Wordの標準機能でテキストに対して、リスト（箇条書き）かつcode（フォントがCourier New）を適用するとキャプションに変換されます。 | 表示/非表示化 |
| キャプション（連番注釈） | Wordの標準機能でテキストに対して、リスト（連番箇条書き）かつcode（フォントがCourier New）を適用するとキャプションに変換されます。 | 表示/非表示化 |

### **３列目**

| **入れられる要素** | **オーサリングルール** | **備考** |
| --- | --- | --- |
| ボタン | ・青ボタン（デフォルト） ： 通常テキストにリンク挿入<br>・白ボタン：通常テキストにリンク挿入＋斜体<br>・枠線ボタン：通常テキストにリンク挿入＋太字＋斜体<br>・オレンジボタン ： 通常テキストにリンク挿入＋取り消し線＋斜体<br>・テキストリンクボタン：通常テキストにリンク挿入＋太字 | 表示/非表示化<br>ページ内リンクを設定するとアンカーリンクスタイルに変換されます。<br>ソフトバンクドメイン以外のリンクの場合は別タブアイコンが付与され、別タブで開きます。 |
| タグ | Word標準機能を使って「箇条書き＋斜体」にするとタグになります。 | 表示/非表示化 |

### **４列目（link-all設定時のみに追加）**

| **入れられる要素** | **オーサリングルール** | **備考** |
| --- | --- | --- |
| 全体リンク | リンク先URLを記入 | カード全体へリンクを設定する場合に使用します。 |

## ▼Cards-lineブロックに適用可能なバリエーション一覧

| **バリエーション名** | **適用内容** | **備考** |
| --- | --- | --- |
| col2<br>col3<br>col4 | 1カラム〜4カラムまでの間でカラム数を指定します。 | ・あしらいが入るため、カラム数を制限<br>・区切り線はカードの間にのみ付与されます。 |
| bg-gray01<br>bg-gray02<br>bg-blue01<br>bg-navy<br>bg-white | カードの背景色を指定します。それぞれのカラーは以下です。<br>・gray01(#F0F0F0)→薄いグレー<br>・gray02(#E3E3E3)→濃いグレー<br>・blue01(#F3F8FF)→薄いブルー<br>・navy(#001A4A)→ネイビー<br>・white→白 | デフォルトでは、背景透過が適用されます。 |
| link-all | カード全体にリンクを設定します。 | 設定するリンクはブロック列の４列目に記載してください。 |
| above-heading | 上から「見出し」→「画像」→「テキスト」の順で配置したい場合に使用します。 | 画像の周りに余白が付与されます。 |
| title-align-left<br>title-align-center<br>title-align-right | カード内の見出しの寄せを指定します。<br>・title-align-left→左寄せ<br>・title-align-center→中央寄せ<br>・title-align-right→右寄せ | 見出しのみの寄せのため、ノーマルテキストには反映されません。 |
| icon-S<br>icon-M<br>icon-L | icon-S：画像がアイコンのSサイズとして表示されます。<br>icon-M：画像がアイコンのM（標準）サイズとして表示されます。<br>icon-L：画像がアイコンのLサイズとして表示されます。 |  |
| heading-l<br>heading-s | カード内の見出しのフォントサイズを変更します。<br>・heading-l（1col: 36px, 2-4col: 32px, 5-6col: 26px）<br>・heading-s（1-4col: 20px, 5-6col: 16px）	 |  |
