# Section Metadata

**プレビューURL**
<br>
https://main--softbank-eds-develop--aquaring.aem.page/module-list/section-metadata

**Section Metadataとは？**
<br>
セクション内で共通のスタイル定義できるブロックのこと
<br>
ブロック毎にテキストの寄せ等を設定する必要がなくなります。

## ▼Section-Metadataで設定可能な項目

| 項目名 | バリエーション | 適用内容 |
| --- | --- | --- |
| Heading-size |h1-xl<br>h1-l<br>h1-s<br>h2-l<br>h2-s<br>h3-l<br>h3-s | **見出しフォントサイズ**を定義します。<br>h1-xl：h1が52px<br>h1-l：h1が46px<br>h1-s：h1が36px<br>h2-l：h2が36px<br>h2-s：h2が26px<br>h3-l：h3が32px<br>h3-s：h3が20px |
| Heading-color | white | **見出しの色**を定義します。<br>white：白（#FFFFFF） |
| Heading-align | left<br>center<br>right | **見出しの寄せ**を定義します。<br>left：左寄せ<br>center：中央寄せ<br>right：右寄せ |
| text-align | left<br>center<br>right | **通常テキストの寄せ**を定義します。<br>left：左寄せ<br>center：中央寄せ<br>right：右寄せ |
| Background-color | white<br>gray-01<br>gray-02<br>blue-01<br>navy<br>カラーコード（例：cccccc）<br>dark| **セクションの背景色**を設定します。<br>white：#FFFFFF（白）<br>gray-01：#F0F0F0（薄いグレー）<br>gray-02：#E3E3E3（濃いグレー）<br>blue-01：#F3F8FF（薄いブルー）<br>navy：＃001A4A（ネイビー）<br>カラーコード：#カラーコード（例：#cccccc）<br>dark：カラーコード指定時に背景色が暗い場合は合わせて指定ください。見出し・テキスト色やボタン色が白色になります。 |
| image-align | left<br>center<br>right | **画像の寄せ**を定義します。<br>left：左寄せ<br>center：中央寄せ<br>right：右寄せ |
| content-width	| narrow | **セクションの横幅**を定義します。<br>default：最大1200px（デフォルト）<br>narrow：最大950px |
| section-type | point | ※導入事例用<br>**セクションの装飾タイプ**を定義します。<br>point：アイコンつきの「POINT」画像が付与され、青線枠でかこまれる |
| Style | table-top-text-left<br>table-top-text-center<br>table-top-text-center<br>s-spacing<br>xs-spacing  | **テーブル上のテキストの寄せ**を定義します。<br>table-top-text-left ：左寄せ<br>table-top-text-center ：中央寄せ<br>table-top-text-center ：右寄せ<br>**セクションの上下余白を調整します。**<br>s-spacing：32px<br>xs-spacing：16px |
