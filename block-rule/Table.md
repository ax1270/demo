### ▼各セル内のオーサリングルール

- セルごとにWord機能でのテキスト寄せが反映されます

| **入れられる要素** | **オーサリングルール** | **備考** |
| --- | --- | --- |
| 見出し | Wordのフォントスタイルを「見出し6」に設定 |  |
| ノーマルテキスト | Wordのフォントスタイルを「ノーマル」に設定 | 斜体・太字・下線も指定可能 |
| 箇条書きテキスト | Word標準の箇条書き機能を使用 |  |
| 連番テキスト | Word標準の連番箇条書き機能を使用 |  |
| キャプション（注釈） | Wordの標準機能でテキストに対して、リスト（箇条書き）かつcode（フォントがCourier New）を適用するとキャプションに変換されます。 |  |
| キャプション（連番注釈） | Wordの標準機能でテキストに対して、リスト（連番箇条書き）かつcode（フォントがCourier New）を適用するとキャプションに変換されます。 |  |
| テーブル | 入れ子にしたテーブル（テーブル内テーブル）ではセル結合が反映されます |  |

| **バリエーション名** | **適用内容** | **備考** |
| --- | --- | --- |
| gray01<br>gray02<br>gray03 | 見出しセル（th）の背景色を指定します。それぞれのカラーは以下です。<br>・gray01(#f0f0f0)→薄いグレー<br>・gray02(#d9d9d9)→濃いグレー<br>・gray03(#bfbfbf)→さらに濃いグレー | 何も設定していない場合は、背景透過が適用されます。 |
